# Безопасная миграция LG TV → HA → HomeKit

Это инструкция перехода на опубликованные релизы. Выполняйте установку отдельно, после резервного копирования HA.

## До публикации

1. Указать GitHub owner в manifest обоих проектов (documentation, issue_tracker, codeowners).
2. Создать fork исходного LG репозитория с сохранением истории; второй репозиторий — lg_tv_homekit.
3. Проверить diff, тесты, лицензию, отсутствие личных файлов. Не публиковать корень этой рабочей папки,
   CONTINUE_IN_CODEX.md, .venv или исходные пользовательские артефакты.
4. После отдельного разрешения отправить код и запустить HACS/hassfest/тестовые workflows.
   Устранить реальные ошибки проверок до релиза. Для HACS-проверки первого релиза может потребоваться
   сначала создать draft и после готовности опубликовать ZIP; не обходить проверки молча.
5. Версия manifest должна совпадать с тегом: v2.0.2 и v0.2.0. Приложить соответствующий ZIP и checksum.
   Архив содержит файлы интеграции в корне; это формат HACS zip_release.

## Перед изменениями HA

1. Подтвердить фактические версии HA, bscpylgtv и lg_tv_homekit через UI/manifest.
   Совпадение upstream 2.0.1 не подтверждает побайтовое совпадение установленной вручную копии.
2. Проверить питание и яркость сейчас. Записать текущие entity IDs, режим Inputs и источник HACS.
3. Сделать штатный backup HA или согласованный snapshot всего config при остановленном контейнере.
   Хранить backup приватно; не присылать .storage, токены и pairing secrets.
   Отдельно сохранить обе папки custom_components и configuration.yaml.
4. Уточнить имя контейнера и host-путь config в Synology Container Manager → Volume Settings.
   Не подставлять предполагаемые значения из старых инструкций.
5. Проверить существующий HomeKit exporter TV в режиме Accessory. Сохранить общий HomeKit Bridge.
   Не удалять записи Devices & services, устройства, сущности или аксессуар из Apple Home.

## Смена источника bscpylgtv

1. Работать в окно обслуживания. Не обновлять одновременно HA.
2. В HACS открыть текущий LG репозиторий и убрать его из управления перед установкой форка.
   В HACS 2.x названия Remove/Delete и последствия диалога могут различаться: проверить текст.
   Если удаляется папка интеграции, восстановить/заменить её форком до перезапуска HA.
   Это операция HACS, НЕ Delete integration в Settings → Devices & services.
3. Добавить URL форка через HACS → Custom repositories → Integration, скачать закреплённый релиз 2.0.2.
   Если HACS не позволяет сменить источник из-за совпадения domain — остановиться;
   не устанавливать второй domain и не удалять настроенное устройство для обхода.
4. Убедиться, что только один HACS репозиторий управляет custom_components/bscpylgtv.
5. Check configuration, полный restart HA. Проверить логи и существующие entity IDs.
   Старый MAC автоматически сохраняется как ручной override; убедиться, что Configure показывает рабочий адрес.
6. Проверить On → Off → повторный Off; отдельно Screen Off → полное Off → WOL On.
   Проверить ещё раз после reconnect и restart. Если не работает — откатить этот этап до обновления адаптера.

## Обновление lg_tv_homekit

1. Добавить отдельный репозиторий в HACS и установить 0.2.0 поверх существующего domain.
2. Сохранить существующий YAML, entity IDs, show_inputs/include_sources и exporter TV.
   Не копировать пример с заменой имён сущностей.
3. Check configuration, полный restart. Проверить существующий сопряжённый TV в Apple Home.
4. Backlight 30 → Off (TV включён) → 60; изменение number через HA; TV Off → попытка яркости
   не будит TV; последующий On не применяет отложенную яркость. Проверить Inputs и пульт.
5. Проверить остальные устройства общего моста. Раскладка Apple Home проверяется на iPhone отдельно.
6. Старую неработающую WOL-автоматизацию лишь проверить: если она использует удалённый trigger/button,
   отключить отдельно после подтверждения. Новая схема WOL её не требует.

## Откат

При ошибках сохранить краткий журнал без секретов и остановить дальнейшую миграцию.
Восстановить сохранённые папки компонентов и YAML, затем restart HA.
Для bscpylgtv возвращать именно локальную рабочую копию с ручными патчами, а не чистый upstream 2.0.1:
upstream снова может перезаписать MAC и выключать только экран.
Новая схема использует minor version 2.2, поэтому для гарантированного возврата старого состояния
предпочтителен полный приватный snapshot config, сделанный до миграции, при остановленном HA.
Не редактировать .storage вручную. Восстановление всего config откатывает и другие изменения после backup.
Не удалять HomeKit pairing, мосты и устройства. Если после восстановления Apple Home показывает
старые сервисы — остановиться и диагностировать отдельно; пересопряжение не является штатным шагом отката.
